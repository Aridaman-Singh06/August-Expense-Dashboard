 August Expense Dashboard
This dashboard analyzes monthly expenses across categories (Food, Medical, Shopping, Travelling).

## Features
- Category-wise expense breakdown
- Sub-item analysis (Zomato, Uber, Zara, etc.)
- Payment method distribution (Card, Cash, UPI, Net-Banking)
- Key influencers for Travelling expenses

## Files
- `AugustExpense.pbix` → Power BI dashboard
- `Dataset.csv` → Source data
- `Dashboard.png` → Screenshot preview

## How to Use
1. Download the `.pbix` file.
2. Open in **Power BI Desktop**.
3. Explore filters and visuals interactive
